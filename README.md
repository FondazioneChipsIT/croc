# Chips-IT Open-Source SoC Design Training

This is the repository for the Open-Source SoC Design from RTL to GDS training.

You will learn how to use and configure a full chip back-end flow built around the [Croc SoC](https://github.com/pulp-platform/croc) and the [IHPs open-source 130nm technology](https://github.com/IHP-GmbH/IHP-Open-PDK/tree/main).

Croc is a ultra low power SoC oriented towards education and developed as part of the PULP project, a joint effort between ETH Zurich and the University of Bologna.

The back-end flow of this course is based on [Librelane](https://github.com/librelane/librelane), a powerful ASIC implementation flow infrastructure that leverages open-source EDA tools.

## Environment

All the flows in this repository were tested on the excellent [IIC-OSIC-TOOLS](https://github.com/iic-jku/IIC-OSIC-TOOLS) docker container, that already provides all the necessary tools.
The current supported version is 2026.04, no other version is officially supported.
